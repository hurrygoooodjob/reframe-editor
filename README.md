# Niuniu

浏览器里的图片塑形工具。整体内容感知缩放、软边保护笔刷，以及眼睛、鼻子、耳朵和肢体比例的局部调整。保留经典 iOS 视觉，适配桌面与手机。当前版本 **2.0.0**。

**[打开 Niuniu](https://hurrygoooodjob.github.io/reframe-editor/)**

图片在设备中处理，无需账户或 API Key，不上传图片。五官/姿态定位使用本地运行的 MediaPipe 模型；首次使用从本站加载模型和运行时。自由点选、推拉与整体编辑不依赖识别成功。

## 使用

1. 打开图片，在「整体」中拖动四边/四角或输入尺寸；随机操作保留形状、形状挤压和过渡柔和度。
2. 「保护」提供保护、压缩、擦除、框选，以及笔刷大小和硬度。绿色选区作用于整体缩放。
3. 「局部」中点图片调整大小，或「定位五官」「定位手臂」后点选部位。展开可独立调宽高、范围和柔和度。手臂默认调粗细，耳朵可点选或使用辅助位置。
4. 「自由推拉」用单指拖动局部；双指缩放/平移视图。电脑可按空格或Alt拖动平移。
5. 对比、撤销、导出PNG；「更多」保存 `.niuniu.json` 工程，仍可打开旧 `.reframe.json`。没有自动保存，关闭前请保存。

先整体、后局部。已有有效局部调整时，整体尺寸和保护选区暂时锁定，避免原来的部位坐标错位。可点击「重置局部，调整整体」，这一步可撤销。保存工程包含局部操作和手动覆盖；历史记录仅保留在当前会话。

## 功能与边界

- 八向整体缩放、双指缩放平移、软笔刷与软擦除。
- 局部椭圆缩放、方向粗细、推拉；最多64个局部操作，最终从原图组合采样，避免累计栅格模糊。
- 自动定位眼睛、鼻子、手臂及辅助耳位置；不是人物身份识别。最多同时定位3个人物/人脸，遮挡与小部位可能需要手动修正。
- 自动选区结合人物概率区域和保守背景分析；随机幅度受可压缩通道限制。无可靠空间时保持尺寸，不强行随机。
- 局部影响范围外保持不动；整体保护画笔不等于局部冻结画笔。局部范围内的邻近内容可能一起移动，请调整范围。
- 非生成式二维变形，不补出遮挡区域或放大后的新细节。规则背景、极端挤压仍可能失真，不承诺完整骨架刚性或物理模拟。
- 30步历史、PNG透明轮廓、JSON工程恢复，旧工程兼容。

现代手机浏览器可用；早期iOS是视觉风格，不代表兼容iOS3/4。手机尺寸和模拟触摸已验证，真实设备的性能、软键盘、下载行为仍可能不同。

输入最多50MiB/4000万像素；导出单边32–8192像素、总计2400万像素；工程最多75MiB。动图按静态处理。

## 本地开发

Node.js22.12+和pnpm，依赖由锁文件固定。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm typecheck
pnpm test
pnpm dev
```

修改算法或识别Worker后运行 `node scripts/build.mjs --worker-only` 并刷新。开发默认端口5178。

`pnpm build` 生成 `dist/index.html` 及同级 `models/`、`vision/` 资源。HTML单独打开可用手动编辑；完整自动定位请通过 `pnpm preview` 或本地启动器访问，并保留全部资源目录。模型文件已随项目附带，无需运行时请求第三方模型服务。

## GitHub Pages与离线包

沿用 main 分支 /docs 发布，不改仓库URL。

```sh
pnpm build:pages
pnpm typecheck
pnpm test
```

应提交完整docs（含模型、WASM、许可），不能只上传index.html。资源相对页面目录加载，支持仓库子路径。离线目录包通过Node启动器运行，首次也无需联网下载模型。

## 结构

- `src/engine/`：整体缩放、局部逆映射、背景容量与软过渡。
- `src/vision/`：按需Worker、部位转换和本地模型入口。
- `src/hooks/`：历史、工程与编辑状态。
- `public/`：固定模型、WASM及对应许可。
- `tests/`：算法、坐标、手动覆盖和工程参数校验。
- `docs/`：GitHub Pages发布目录。
